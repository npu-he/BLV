# 盲人如何用地图 / 导航 —— 实验设计参考

## 真实使用习惯（文献与无障碍实践）

1. **语音优先**：VoiceOver / TalkBack 读屏，或专用 App（BlindSquare、Lazarillo、Seeing Eye GPS）。
2. **先确认「我在哪」**：GPS 播报或手动设点；陌生环境依赖入口/地标锚定。
3. **相对方位 + 距离**：常用「时钟方位」（12点正前）或「左前方/东北约 50 米」；要具体米数。
4. **Look Around / 附近**：主动问「周围有什么」比看地图更常见。
5. **短句、可打断**：一次不要塞太多 POI；重要信息放前。
6. **错误代价高**：一次错误方位会被记住并继续推理 → 必须可验证 + 可纠正。

## 本系统对应

| 用户需求 | 本系统 |
|----------|--------|
| 我在哪 | user_location + 「我在XX」/ 下拉框 |
| XX在我哪边 | relation(A, 我) 指代消解 |
| 离我多远 | distance(A, 我) |
| 附近有什么 | nearby(我) |
| 听得懂 | 短句口语回答 |
| 防错 | SafetyGate + 确定性工具 |

## 用户实验建议（真实盲人）

- 任务：在设定起点下，用对话找到食堂/图书馆/出口（不看屏幕，只听）。
- 指标：任务成功率、完成时间、错误方位次数、是否发现并纠正矛盾、主观信任度。
- 对比：纯 LLM 无工具 vs 本 Agent。
- 伦理：知情同意、可随时退出、不在真实马路做危险任务（先桌面/校园安全区）。
